# KSE Sudan market landing page

The public-facing landing page is a responsive, bilingual (Arabic/English) KSE Sudan market-information template with a Monee-inspired financial design direction.

## Run locally

Requires PHP 7.4+ with sessions enabled. From the repository root, run:

```sh
php -S localhost:8000
```

Then open `http://localhost:8000`.

## Market data

This template does not invent or display live prices. The market panel intentionally shows placeholders until an official data source/API is configured. The contact email is also a placeholder and should be confirmed before launch. The landing page is informational and is not a trading platform or investment advice.
